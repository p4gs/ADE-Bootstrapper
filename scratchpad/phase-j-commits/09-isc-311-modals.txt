feat(design): ISC-311 screen 4/4 — modals onto the Phase J system

- Modals deliberately KEEP their four-layer shadow stack and pop-in — they
  are a different elevation tier than cards; forcing them onto
  elevated_card would flatten that hierarchy. (Their panel fill already
  follows the token layer, so light modals became pure white with the
  cycle-3 inversion automatically.)
- bulk_row's title/command block was the same nested-vertical top-align
  class found on Overview — now centered as one unit via the new shared
  `app::centered_text_block` (extracted from `mark_beside_block`; a
  checkbox row centers the control on the block, only status marks get
  the title-line anchor).
- New `app::ax_checkbox`: the macOS checkbox — accent-filled rounded box
  with a white check when on, visibly bordered box when off, disabled
  state, focus ring, full WidgetInfo. Stock egui's widget-gray box was
  nearly invisible on slate, leaving its check glyph floating unanchored
  (pixel-scanned). Hand-painted like `toggle`, the app's own idiom.
- Measured on the regenerated modal_bulk golden: accent-box centers within
  -1.0/-1.5px of block ink centers (geometric block centering; ink skews
  low with descenders — box-center is the convention for controls, per
  the ISA's triangle adjudication).
